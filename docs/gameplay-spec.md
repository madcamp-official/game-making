# 게임플레이 상세 명세

2026-07-24 팀 기획 합의 기준이다. 구현이 문서와 다르면 이 문서를 우선하며, 미정 항목은 구현을 확정하지 않고 임시값 또는 교체 가능한 구조로 둔다.

## 구현 공통 원칙 — Inspector에서 수치 조정

게임플레이 밸런스에 영향을 주는 모든 수치는 Unity Inspector에서 수정할 수 있어야 한다.

```csharp
[SerializeField] private float moveSpeed;
[SerializeField, Range(0f, 1f)] private float attackMoveSpeedMultiplier;
[SerializeField, Min(1)] private int maxHealth;
```

적용 대상에는 다음이 포함된다.

- 플레이어 이동 속도와 공격 중 이동 속도 배율
- 최대 체력과 피격 후 무적 시간
- 모든 공격의 피해량, 쿨다운, 사거리와 판정 크기
- 투사체 속도, 수명과 충돌 범위
- 적의 체력, 이동 속도, 감지 범위, 공격 범위, 피해량과 쿨다운
- 적 처치 재화, 방 클리어 재화와 회복량
- 진화 단계별 최대 체력과 공격력
- 상점 가격과 체력 회복량
- 결과 화면 표시 시간 등 플레이 감각에 영향을 주는 시간값

코드 안에 조정 수치를 직접 작성하지 않는다. 공용 수치는 추후 `ScriptableObject`로 옮길 수 있도록 컴포넌트의 책임과 분리한다.

## 1. 플레이어 조작 — 확정

| 동작 | 입력·규칙 |
|---|---|
| 이동 | `WASD`, 자유로운 8방향 이동 |
| 조준 | 마우스의 월드 위치 방향 |
| 기본 공격 1 | 마우스 왼쪽 버튼 |
| 기본 공격 2 | 마우스 오른쪽 버튼 |
| 공격 중 이동 | 가능. 평상시보다 이동 속도가 감소함 |
| 방향 표현 | 가장 가까운 8방향 애니메이션 사용 |
| 대시 | 초기 MVP에서 제외 |
| 특수 공격 | 초기 MVP에서 제외 |

공격 중 이동 속도 감소 배율은 아직 미정이다. `attackMoveSpeedMultiplier` 같은 `[SerializeField]` 값으로 구현해 플레이테스트 중 조정한다.

## 2. 공격 구성 — 일부 확정

최종적으로 각 플레이어 캐릭터는 다음 네 개의 공격 슬롯을 가진다.

| 슬롯 | 입력 | MVP 상태 |
|---|---|---|
| 기본 공격 1 | 마우스 왼쪽 버튼 | 포함. 현재 근거리 공격이 구현됨 |
| 기본 공격 2 | 마우스 오른쪽 버튼 | 포함. 잎날가르기 |
| 캐릭터 특수 공격 1 | 미정 | 초기 MVP 제외 |
| 캐릭터 특수 공격 2 | 미정 | 초기 MVP 제외 |

### 기본 공격 1 — 근거리

- 현재 구현된 근거리 공격을 유지한다.
- 마우스 왼쪽 버튼으로 입력을 변경한다.
- 마우스 조준 방향을 기준으로 공격 판정을 생성한다.
- 이름, 피해량, 사거리, 판정 크기와 쿨다운은 아직 임시값이다.
- 모든 수치는 `[SerializeField]`로 조정할 수 있어야 한다.

### 기본 공격 2 — 잎날가르기

- 마우스 오른쪽 버튼으로 사용한다.
- 마우스 조준 방향으로 직선 투사체 한 발을 발사한다.
- 벽 또는 적과 충돌하면 즉시 사라진다.
- 적을 관통하지 않는다.
- 기본 공격 간격은 약 `0.5초`다.
- 공격력은 임시값을 사용한다.
- 피해량, 쿨다운, 투사체 속도, 투사체 수명과 충돌 범위를 `[SerializeField]`로 제공한다.

두 기본 공격의 쿨다운을 서로 공유할지 독립적으로 관리할지는 미정이다. 구현 시 서로 독립적인 값으로 노출해 두 방식 모두 플레이테스트할 수 있게 한다.

## 3. 체력, 피격과 사망 — 확정

- 플레이어 기본 최대 체력은 `100`이다.
- 적의 공격과 적 접촉으로 피해를 받는다.
- 피격 직후 약 `0.5초` 동안 무적 상태가 된다.
- 무적 시간 중에는 추가 피해를 받지 않는다.
- 체력이 `0`이 되면 현재 런을 종료한다.
- 사망 후 결과 화면을 표시한다.
- 결과 화면에서 새 런을 다시 시작할 수 있다.
- 공통 낙사 및 함정 시스템은 초기 MVP에 포함하지 않는다.
- 특정 층의 맵 기믹으로 낙사나 함정을 추가할 수는 있지만 후순위다.

최대 체력, 무적 시간, 접촉 피해량과 공격 피해량은 모두 `[SerializeField]`로 조정한다.

## 4. 일반 전투방 — 확정

```text
플레이어 입장
→ 출구 폐쇄
→ 준비된 적이 한 번에 등장
→ 전투
→ 적 전멸
→ 전투방 보상 제공
→ 출구 활성화
→ 출구 접촉 시 다음 방 이동
```

- 웨이브 방식은 초기 MVP에서 사용하지 않는다.
- 일반 전투방 하나의 목표 플레이 시간은 `45~60초`다.
- 각 적은 사망할 때 재화를 떨어뜨린다.
- 전투방 클리어 시 재화 또는 체력 회복 중 하나를 추가로 획득한다.
- 적 전멸과 보상 처리가 끝난 후 출구를 활성화한다.

적별 재화량, 방 클리어 재화량과 체력 회복량은 `[SerializeField]`로 조정한다.

## 5. 방별 보상 — 일부 확정

| 방 종류 | 보상 규칙 |
|---|---|
| 일반 전투방 | 상점 재화 또는 체력 회복 중 하나 |
| 이벤트방 | 각 층의 고정 이벤트와 보상. 세부 내용 미정 |
| 상점방 | 재화로 체력 회복 또는 유물 구매 |
| 보스방 | 1·2층은 진화와 유물 1개, 3층은 게임 클리어와 유물 처리 추후 확정 |

일반 전투방 보상이 자동으로 결정되는지 플레이어가 선택하는지는 아직 미정이다.

## 6. 진화 — 확정

```text
게임 시작: 이상해씨
1층 버터플 처치: 이상해풀 진화
2층 코뿌리 처치: 이상해꽃 진화
3층 갸라도스 처치: 게임 클리어
```

진화 시 다음 효과를 적용한다.

- 최대 체력 증가
- 체력 완전 회복
- 공격력 증가
- 현재 진화 단계의 스프라이트로 변경
- 현재 진화 단계의 Animator Controller로 변경

진화 단계별 최대 체력과 공격력은 Inspector 또는 캐릭터 데이터에서 수정할 수 있어야 한다. 진화에 따른 새로운 기술 추가는 후순위다.

## 7. 행복의알 — 미정

정확한 발동 시점, 지속 여부와 진화 처리 규칙을 추후 정한다. 규칙이 확정되기 전에는 최종 효과를 구현하지 않는다.

## 8. 자뭉열매 — 미정

부활 시 복구 범위, 소비 여부와 회복 상태를 추후 정한다. 규칙이 확정되기 전에는 최종 효과를 구현하지 않는다.

## 9. 층별 일반 적 — 미정

층별 적 종류, 행동, 수치와 보상은 추후 확정한다.

## 10. 보스 패턴 — 미정

버터플, 코뿌리, 갸라도스의 공격 패턴과 단계 전환은 추후 확정한다.

## 11. 이벤트방 — 미정

1층 잠만보 이벤트를 포함한 각 층 이벤트의 선택지와 보상은 추후 확정한다.

## 12. 재화와 상점 — 확정

- 재화 종류는 하나만 사용한다.
- 적 처치와 일반 전투방 클리어 보상으로 획득한다.
- 상점에는 항상 상품 세 개를 표시한다.
  - 체력 회복 1개
  - 무작위 유물 1개
  - 무작위 유물 1개
- 두 유물 상품은 상품 목록에서 무작위로 선정한다.
- 한 상품은 한 번만 구매할 수 있다.
- 구매한 상품은 해당 상점에서 다시 구매할 수 없다.
- 새로고침과 판매 기능은 초기 MVP에서 제외한다.

상품 가격, 체력 회복량과 유물 상품 목록은 Inspector 또는 데이터 에셋에서 수정할 수 있어야 한다.

## 현재 구현과의 차이

`dev` 브랜치의 2026-07-24 구현을 기준으로 다음 변경이 필요하다.

| 현재 구현 | 합의된 명세 |
|---|---|
| `Space`로 근거리 공격 | 왼쪽 클릭 근거리, 오른쪽 클릭 잎날가르기 |
| 마지막 이동 방향으로 공격 | 마우스 위치 방향으로 조준 |
| 공격 중 별도 감속 없음 | 공격 중 이동 가능, 속도 감소 |
| 플레이어 최대 체력 기본값 `10` | 플레이어 기본 최대 체력 `100` |
| 무적 시간 기본값 `0.3초` | 플레이어 무적 시간 약 `0.5초` |
| 근거리 공격 하나 | MVP 기본 공격 두 개 |

이 표는 구현 담당자에게 필요한 변경 목록이며, 이 문서 작업에서는 Unity 코드와 Prefab을 수정하지 않는다.
