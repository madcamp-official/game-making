# 게임 기획 개요

## 1. 프로젝트 콘셉트

포켓몬을 주인공으로 하는 스프라이트 기반 탑다운 로그라이크입니다. 포켓몬 불가사의 던전과 같은 시점과 이동 방식을 사용하며, 한 판 안에서 전투, 이벤트, 상점, 보스전을 차례로 경험합니다.

## 2. 게임 흐름

- 한 판의 예상 플레이 시간은 15~20분입니다.
- 전체 게임은 3개 층으로 구성됩니다.
- 각 층은 타이니 로그형 직선 구조로 진행됩니다.

```text
전투방 → 이벤트방 → 전투방 → 상점방 → 보스방
```

1층과 2층의 보스를 처치하면 플레이어 캐릭터가 진화하고 다음 층으로 이동합니다. 3층 보스 처치는 게임 클리어 조건입니다.

조작, 전투, 보상과 상점에 관한 확정 규칙은 [게임플레이 상세 명세](gameplay-spec.md)를 기준으로 구현합니다.

## 3. 층별 구성

| 층 | 환경 | 보스 | 이벤트 콘셉트 |
|---|---|---|---|
| 1층 | 숲 | 버터플 | 잠만보가 길을 막고 있음 (깨우면 비켜주며 유물을 남김) |
| 2층 | 사막 | 코뿌리 | 오아시스 — 쉬어가며 체력을 회복하고 골드를 줍는다 |
| 3층 | 바다 | 갸라도스 | 가라앉은 보물상자 — 열면 골드와 유물을 얻는다 |

## 4. 플레이어

- 최초 플레이어블 캐릭터는 이상해씨 진화 계열입니다.
- 기본 진화 흐름은 `이상해씨 → 이상해풀 → 이상해꽃`입니다.
- 1층 보스 처치 후 이상해풀로 진화합니다.
- 2층 보스 처치 후 이상해꽃으로 진화합니다.
- 진화하면 최대 체력과 공격력이 증가하고 체력을 완전히 회복합니다.
- 진화 단계에 맞게 스프라이트와 Animator Controller를 변경합니다.
- 진화에 따른 새로운 기술 추가는 후순위입니다.

## 5. 유물 시스템

슬레이 더 스파이어의 유물과 유사한 지속 효과 아이템 시스템입니다. 유물은 이벤트, 상점 또는 보스 처치 보상으로 획득할 수 있습니다.

### 유물 목록

| 이름 | 효과 | 비고 |
|---|---|---|
| 행복의알 | 해당 층의 보스방에 진입하기 전에 진화할 수 있음 | 세부 획득 조건 및 발동 시점 추후 확정 |
| 자뭉열매 | 기절했을 때 해당 방에 진입하기 전 상태로 부활 | 소비 여부 및 회복 수치 추후 확정 |

유물과 효과는 개발 과정에서 계속 추가합니다.

## 6. 추가 구현 우선순위

1. 플레이어 캐릭터 추가
   - 파이리 진화 계열
   - 꼬부기 진화 계열
   - 캐릭터별 밸런스 조정
2. 방 선택지 확장
   - 전투방 선택지 다양화
   - 보상방 선택지 다양화

## 7. 미정 사항

- 2층 이벤트의 구체적인 내용
- 3층 이벤트의 구체적인 내용
- 기본 공격 1의 이름과 최종 수치
- 공격 중 이동 속도 감소 배율
- 유물별 획득 조건, 중첩 및 소비 규칙
- 층별 일반 적 구성
- 보스별 공격 패턴
- 층별 이벤트의 상세 선택지와 보상
