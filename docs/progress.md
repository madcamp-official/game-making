## 맵 타일 (2026-07-25)

- 환경 타일셋(`Assets/Game/Art/Environment/Forest·Desert·Sea.png`, PMD 공식 유래 립)을 24px 그리드로 슬라이스해 15개 방 전부 Tilemap 적용.
- 각 방: 바닥 타일 + 변형 스프링클, 안쪽을 향한 자연스러운 벽 링(문 통로 제외), 층 테마별 지형 — 숲: 꽃밭·연못, 사막: 오아시스(이벤트 연못이 실제 물 타일), 바다: 깊은 물웅덩이.
- 연못/웅덩이에는 통행 차단 콜라이더가 있다. 원본 시트는 `Assets/ThirdParty/Tilesets_original/` 백업.
- 타일 에셋은 `Assets/Game/Art/Environment/Tiles/`에 자동 생성 (`{시트}_{열}_{행}` 명명).

## 버그 수정 (2026-07-25)

| 증상 | 원인 | 조치 |
|---|---|---|
| 진화 직후 벽을 통과 | `PlayerEvolution`이 연출 시작 시 Rigidbody2D를 Kinematic으로 바꾸고 "원래 타입"을 기억해 되돌렸다. 연출이 끝나기 전에 `Evolve()`가 다시 불리면 두 번째 연출이 원래 타입을 Kinematic으로 기억하고, 연출 도중 예외·중단이 나면 복구 코드에 도달하지 못해 Kinematic으로 남았다 (= 벽 통과) | 연출 중 재진입 차단(`IsEvolving`), 단계 번호를 연출 시작과 동시에 확정, 복구를 `finally`로 옮기고 기억한 값 대신 항상 `Dynamic`으로 되돌린다 |
| 잠만보를 지나쳐 뒤로 갈 수 있음 | 잠만보 충돌체가 방 전체 폭에 비해 작아 위아래로 돌아갈 수 있었다. 게다가 `SpriteRenderer`에 스프라이트가 없어 화면에 보이지도 않았다 | 방 오른쪽에 2칸 폭 나무 칸막이(`Wall_Partition_Top/Bottom` + 타일)를 세워 2×2 통로만 남기고, 잠만보 충돌체가 그 통로를 완전히 덮도록 조정. 스프라이트(`Sleep_7_0`) 지정 |
| 피격 시 화면이 과하게 흔들림 | 흔들림 오프셋을 `transform.position`에 직접 더해서, 흔들린 좌표가 다음 프레임 `SmoothDamp`의 시작점이 되어 흔들림이 감속 운동에 누적됐다 | 추적 위치와 흔들림 오프셋을 분리하고 시간에 따라 잦아들게 변경. 진폭 0.12 → 0.04, 지속 0.15 → 0.12초 |
| 이동 중 파란 선이 깜빡임 | 타일시트의 타일 간격 1px이 밝은 청록(Forest/Desert `#80FFFF`, Sea `#FF80FF`) 격자선이라, 확대 배율이 정수가 아닌 상황에서 타일 가장자리로 새어 나왔다 | 세 시트를 타일마다 2px 여백을 두고 가장자리 픽셀을 늘려 채운 형태로 재포장(간격 25 → 28px). 슬라이스 이름·ID를 그대로 유지해 기존 타일 에셋 61개 참조는 전부 보존. Mesh Type도 Full Rect로 변경 |

## 조작

- 이동: `WASD` / 방향키 (8방향)
- 공격: 마우스 좌클릭 — 캐릭터 기준 마우스 방향으로 360도 자유각 공격
- 상호작용: `E`
- 재시작(게임 오버/클리어): `R`

## 주요 시스템 위치

- 방 흐름: `RoomFlowController` (씬) — `FloorData` SO(`Assets/Game/Data/Floors/`) 3개로 층 구성, 방 프리팹 `Assets/Game/Prefabs/Rooms/` (층당 5개)
- 런 상태: `RunManager`(골드) + `RelicManager`(유물) — 같은 씬 오브젝트
- 유물 데이터: `Assets/Game/Data/Relics/*.asset` (`RelicData` SO)
- 진화: `PlayerEvolution` (플레이어, 단계 배열) — 보스 처치 또는 행복의알로 발동
- HUD: `UIManager` (HUDCanvas) — 골드/방/힌트/메시지/유물 바
- 캐릭터 스프라이트 파이프라인: PMDCollab 시트 → 8방향 슬라이스 → 클립/컨트롤러 자동 생성
