# 코뿌리 보스 구현 명세

> 대상: `F2Room7_Boss`의 `Boss_Rhydon` — 2층 보스
> 구현: `Assets/Game/Scripts/Combat/Bosses/RhydonBossController.cs`
> 기준 단위: Unity 월드 단위. 타일 1칸과 플레이어 폭이 각각 약 `1 unit`이다.

## 0. 핵심 요구사항

- 패턴은 정확히 3종: `스톤샤워`, `뿔드릴`, `이판사판`.
- **세 패턴 모두 근접 공격이다. 투사체를 하나도 쓰지 않는다.**
- 체력 50%에서 2페이즈로 넘어가고, 새 패턴 없이 같은 셋의 강화형만 쓴다.
- 난도는 버터플의 2배 이상.

버터플과 정반대의 보스다. 버터플은 거리를 벌리고 탄을 뿌리지만, 코뿌리는 몸이 닿는 거리에서만
위험하다. 그래서 압박이 "탄을 피해라"가 아니라 "어디에 서 있을 것이냐"로 온다.

## 1. 기본 수치

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 최대 체력 | `700` | 버터플 240의 2.9배 |
| 걷기 속도 | `3.4` | 플레이어는 5. 느린 대신 돌진이 빠르다 |
| 접촉 피해 | `14` / 1초 | 돌진 중에는 적용하지 않는다 |
| 전투 영역 | 반너비 `6.2` × 반높이 `4.2` | 방 벽은 ±7.25, ±5.25 |
| 넉백 | 면역 (`knockbackMultiplier = 0`) | 패턴 위치가 무너지면 안 된다 |

`EnemyController`의 기본 추적 AI는 꺼 둔다(`basicAIEnabled = 0`). 이 컨트롤러가 직접 Rigidbody를
움직이므로, 둘이 동시에 속도를 쓰면 서로 덮어쓴다.

패턴 선택은 버터플과 같은 셔플 백이다. 세 패턴을 한 번씩 다 쓰기 전에는 같은 패턴이 다시 나오지
않고, 백을 다시 채울 때 직전 패턴이 맨 앞이면 뒤로 민다.

## 2. 스톤샤워

코뿌리를 중심으로 갈색 원이 깔리고, 그 안에 돌이 하늘에서 하나씩 떨어진다.

**원이 곧 코뿌리 주변이다.** 때리려면 원 안에 있어야 하고, 원 안에 있으면 맞는다. 이 패턴만큼은
공격을 포기하고 나가는 게 정답이다. 그래서 시전 전에 플레이어에게 `1.6`까지 붙는다 — 붙지 않으면
원이 엉뚱한 데 깔려 아무 의미가 없다.

떨어질 자리는 40% 확률로 플레이어의 현재 위치, 나머지는 원 안 무작위다. 전부 무작위면 원 안에서
가만히 서 있는 게 통해 버린다. 무작위 지점은 반지름에 √를 씌워 뽑아야 원 안에 고르게 흩어진다.

각 돌은 그림자가 먼저 뜨고, 낙하 시간 뒤에 착탄한다. 착탄 판정은 `0.22`초만 남아서 지나간 자리는
곧 다시 안전해진다.

| 항목 | 1페이즈 | 2페이즈 | 변화 |
| --- | --- | --- | --- |
| 원 반지름 | `3.2` | `3.92` | **넓이 +50%** (반지름 ×√1.5) |
| 낙하 시간 | `0.70` | `0.538` | **속도 +30%** (시간 ÷1.3) |
| 예고 | `0.70` | `0.60` | |
| 돌 수 | `9` | `13` | |
| 투하 간격 | `0.24` | `0.20` | |
| 후딜 | `0.75` | `0.60` | |

돌 하나: 반지름 `0.62`, 피해 `22`.

2페이즈 반지름 `3.92`는 전투 영역 반높이 `4.2`에 가깝다. 세로로는 빠져나갈 틈이 거의 없고
가로(반너비 `6.2`)로 도망쳐야 한다 — 의도한 압박이다.

## 3. 뿔드릴

짧게 차지한 뒤 거대한 삼각뿔을 창처럼 찌른다. 뻗기 → 유지 → 들어가기의 세 단계이고,
**뻗어 나온 길이만큼만 판정이 있다.** 끝으로 갈수록 좁아지는 삼각형 모양을 그대로 판정하므로,
예고로 그린 삼각형과 실제로 맞는 범위가 정확히 같다.

한 번의 패턴에서 두 번 찌르고, 찌를 때마다 다시 조준한다. 첫 찌르기를 피한 자리에 그대로 서 있으면
두 번째에 맞는다. 찌르면서 몸도 앞으로 밀고 나간다.

시전 전에 `2.4`까지 붙는다 (뿔 길이보다 짧아야 한다).

| 항목 | 1페이즈 | 2페이즈 | 변화 |
| --- | --- | --- | --- |
| 차지 시간 | `0.75` | `0.42` | **-44%** |
| 뿔 길이 | `3.4` | `4.5` | **+32%** |
| 뿔 밑변 | `1.7` | `2.4` | **+41%** |
| 전진 거리 | `0.9` | `1.2` | |
| 찌르기 간격 | `0.28` | `0.22` | |
| 후딜 | `0.80` | `0.65` | |

피해 `26`. 한 번의 찌르기에 한 번만 맞는다.

## 4. 이판사판

조준한 방향으로 방 반대편까지 그대로 밀고 나간다. 연속으로 여러 번 하고, 돌진마다 다시 조준한다.

돌진 방향은 시작할 때 고정한다. 매 프레임 목표 쪽으로 다시 겨누면, 프레임이 길어 한 번에 목표를
지나친 순간 뒤로 돌아 제자리에서 앞뒤로 튄다.

돌진 중에는 접촉 피해를 끄고 더 아픈 돌진 피해를 쓴다. 둘 다 들어가면 두 배로 아프다.

| 항목 | 1페이즈 | 2페이즈 | 변화 |
| --- | --- | --- | --- |
| 돌진 횟수 | `3` | `5` | **+2회** |
| 돌진 속도 | `15` | `19.5` | **+30%** |
| 조준 시간 | `0.42` | `0.34` | |
| 돌진 간격 | `0.20` | `0.16` | |
| 후딜 | `0.90` | `0.70` | |

피해 `24`, 들이받는 반지름 `1.05`. 이 패턴만은 미리 붙지 않는다 — 어차피 방 반대편까지 간다.

## 5. 페이즈 전환

체력이 50% 이하가 되면 요청만 기록하고, **실행 중인 패턴은 정상적으로 끝낸 뒤** 전환한다.
전환 중에는 무적이고, 남아 있던 예고·떨어지던 돌·착탄 판정을 전부 지운다. 몸이 커졌다 돌아오고
충격파가 퍼진 뒤 `0.6`초의 인지 시간을 준다.

전환 시 셔플 백을 비워, 강화 패턴을 특정 패턴으로 고정하지 않고 새로 뽑는다.

## 6. 구현 주의점

- **삼각형 스프라이트** — `PrimitiveSprites.Triangle`. 밑변이 -X, 꼭짓점이 +X다. `localScale`을
  (길이, 밑변 너비)로 주면 창끝이 된다. `AttackTelegraph.CreateTriangle`이 예고에 쓴다
- **떨어지는 돌과 뿔은 캐릭터보다 앞에 그린다** (`sortingOrder = 12`). 공중에 있는 것이라 캐릭터(10)
  뒤로 가면 어디에 떨어지는지 안 보인다
- **공격 오브젝트는 씬 루트의 `Rhydon_Attacks` 아래에 만든다.** 보스(1.2배) 아래에 두면 돌과 뿔까지
  같이 커진다. 사망·방 이동 시 통째로 지운다
- **`holdPosition` 플래그로 몸을 붙든다.** 예고·후딜에서는 매 프레임 속도를 0으로 눌러 플레이어와
  부딪혀 밀리지 않게 하고, 접근·전진·돌진에서만 푼다
- **떨어지는 중인 돌은 `attackGeneration`으로 무효화한다.** 페이즈 전환이 돌을 지운 뒤에도 코루틴은
  계속 돌기 때문에, 세대가 바뀌었으면 착탄시키지 않는다 (버터플 독가루와 같은 장치)
- **시전 방향 고정은 반드시 풀어야 한다.** `EnemyAnimator.SetActionState("Idle", 방향)`으로 멈춰 선
  동안에도 플레이어를 보게 하는데, `ClearActionState()`를 빠뜨리면 패턴이 끝난 뒤에도 그 방향으로
  굳은 채 걷는다
- 코뿌리 애니메이터에는 `Idle`/`Walk` 8방향만 있다. `Charge` 시트가 없어 차지는 색으로만 알린다
  (`windupTint`) — `SetActionState`는 없는 상태를 조용히 무시한다
- **2층 바닥이 밝은 모래색이라 예고 색을 골라야 한다.** 처음에 뿔 예고를 노랑(α 0.42), 뿔 자체를
  흰색에 가깝게 뒀더니 화면에서 **아예 보이지 않았다.** 버터플이 초록 바닥에서 겪은 것과 같은 문제라
  같은 규칙(위험 = 진한 빨강)으로 맞췄다: 예고 `(0.85, 0.1, 0.28, 0.62)`, 뿔은 어두운 강철색
  `(0.22, 0.24, 0.3)`. **예고 색을 바꿀 때는 반드시 실제 화면을 찍어 확인할 것**
