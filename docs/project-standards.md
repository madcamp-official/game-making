# 단계 0 — 프로젝트 기준 (확정)

2026-07-24 확정. 로드맵 단계 0의 결정 사항을 기록한다.

## 엔진과 프로젝트 설정

| 항목 | 값 | 상태 |
|---|---|---|
| Unity 버전 | `6000.5.3f1` | 확인 완료 |
| 렌더 파이프라인 | URP 2D (Universal 2D 템플릿) | 확인 완료 |
| Version Control Mode | `Visible Meta Files` | 확인 완료 |
| Asset Serialization | `Force Text` | 확인 완료 |
| 입력 시스템 | Input System (신형) 전용, `activeInputHandler: 1` | 확인 완료 |

## 기준 해상도

- 기본 해상도: **1920×1080 (16:9)**
- 카메라: Orthographic, Size 5 기준으로 시작 (플레이테스트 후 조정)

## 입력 키

| 동작 | 키 |
|---|---|
| 이동 (8방향) | `WASD` |
| 조준 | 마우스 위치 |
| 기본 공격 1 — 근거리 | 마우스 왼쪽 버튼 |
| 기본 공격 2 — 잎날가르기 | 마우스 오른쪽 버튼 |

- 공격 중에도 이동할 수 있지만 이동 속도가 감소한다.
- 대시와 캐릭터별 특수 공격은 초기 MVP에서 제외한다.
- 이동과 공격 방향은 가장 가까운 8방향 애니메이션으로 표현한다.

## 전투 방식 (최종 확정)

**실시간 8방향 이동 + 실시간 전투**로 확정한다. 격자 턴제로 전환하지 않는다.
(로드맵 2절의 기본안을 그대로 채택. 개발 중간 전환 금지.)

세부 규칙과 현재 구현의 변경 요구사항은 [게임플레이 상세 명세](gameplay-spec.md)를 따른다.

## 게임플레이 수치 구현 기준

기획자가 Unity Inspector에서 밸런스를 조정할 수 있도록 게임플레이에 영향을 주는 수치는 하드코딩하지 않는다.

- 이동 속도, 공격 중 이동 배율, 체력, 피해량, 사거리, 판정 크기, 쿨다운, 무적 시간, 투사체 속도와 수명, 적 감지 범위, 재화량, 회복량, 가격 등은 `[SerializeField]`로 노출한다.
- 다른 클래스가 값을 읽어야 하면 public field 대신 읽기 전용 프로퍼티를 제공한다.
- 런타임에서 값 변경이 필요하면 의도가 분명한 메서드를 제공한다.
- 유효 범위가 있는 값에는 `[Min]` 또는 `[Range]`를 사용해 잘못된 Inspector 입력을 방지한다.
- 여러 캐릭터나 적이 공유하는 수치는 추후 `ScriptableObject` 데이터로 옮길 수 있게 분리한다.
- 애니메이션 상태 번호, 레이어 마스크처럼 수치로 표현되지만 설정에 가까운 값도 Inspector 또는 명명된 상수로 관리한다.

## 폴더 구조

로드맵 6절의 `Assets/Game` 구조를 그대로 사용한다. 외부 원본은 `Assets/ThirdParty/PMDCollab`에 둔다.

## 스프라이트 공통 값

- Pixels Per Unit: **32** (첫 캐릭터 + 타일 테스트 후 한 번만 재조정 가능)
- Filter Mode: `Point (no filter)`, Compression: `None`, Mip Maps: 끔
- Pivot: 캐릭터 발 위치 기준

## Git

- `.gitignore`는 프로젝트 루트의 Unity 표준 규칙 사용 (`Library`, `Temp`, `Logs`, `UserSettings` 등 제외)
- 커밋에 `.meta` 파일 포함, Scene/Prefab 동시 수정 금지 (로드맵 10절 참고)
