### 고지에서 특히 볼 것

`Attack` 시트는 0.37초짜리인데 **마지막 프레임(0.35초)이 "몸을 다시 편" 그림**이다.
구르는 시간은 `dashDistance ÷ dashSpeed` = 2.8 ÷ 10 = **0.28초**라 거기에 닿지 않는다.
**구르는 거리를 늘리거나 속도를 낮출 때는 이 곱이 0.35초를 넘지 않는지 반드시 확인할 것** —
넘기면 굴러가는 도중에 몸이 펴진 그림이 한 번 스친다.

## 작업 규칙

이 저장소에서 지켜 온 것들. 새 환경에는 따라가지 않으므로 여기 적어 둔다.

- **작업이 끝나면 묻지 말고 `dev`에 커밋·푸시한다.** 충돌도 직접 해결한다
- **빌드 검증은 `dotnet build`로 한다** (Unity MCP가 없어도 된다)
  ```bash
  dotnet build Assembly-CSharp.csproj -v q -nologo
  ```
  에디터 스크립트를 건드렸으면 `Assembly-CSharp-Editor.csproj`도 함께
- 커밋 메시지·주석·문서 전부 한국어. 주석은 "무엇을"이 아니라 **"왜 이렇게 했는가"**를 적는다
- 작업 배경은 `docs/progress.md`에 절마다 남긴다

## 밟기 쉬운 함정

- **`Assembly-CSharp.csproj`는 파일을 더하거나 지우면 낡는다.** Unity가 다시 만들어 주지만,
  에디터를 켜지 않고 빌드하려면 `<Compile Include>` 줄을 손으로 넣고 빼야 한다.
  새 스크립트에는 `.meta`도 함께 만들 것 (없으면 팀원과 GUID가 갈린다)
- **`git pull` 뒤에는 Unity에서 씬을 다시 열 것.** 에디터가 메모리에 들고 있는 씬은
  디스크가 바뀌어도 갱신되지 않는다. `scene.isDirty == false`는 "디스크와 같다"가 아니라
  "에디터가 편집하지 않았다"는 뜻이다. 구름이 전부 사라진 줄 알았던 일이 이것이었다
  (`progress.md`의 "에디터의 씬이 낡아 있었다")
- **`Floor2EnemySetup.ApplyRework`를 함부로 돌리지 말 것.** 2층 수치의 원본이지만,
  프리팹에 직접 넣은 조정과 어긋나면 그 조정이 통째로 되돌아간다. 지금은 맞춰 두었다.
  값을 고칠 일이 있으면 **여기서 고치고 재실행**하는 쪽이 맞다
- `Floor2EnemySetup.BuildPrefabs`는 스라크를 본으로 **새로 뜨는 것**이라 그림자 짝이 깨진다.
  살아 있는 프리팹에는 `ApplyRework`만 쓸 것
- **`WallMap`에는 `TilemapCollider2D`가 없다.** 방 벽은 `Wall_*` 박스 콜라이더 넷뿐이고
  x ±7.25에서 끝난다. 통로 위아래에는 아무것도 없으니, 통로를 걸어 다니게 만들 생각이라면
  콜라이더부터 세워야 한다

## 열려 있는 것

- **`MoveSlotsHud.cs:138` NullReferenceException** — 이전 플레이 세션에서 매 프레임 쏟아졌으나
  지금은 재현되지 않는다. `slots[i]`가 null이라는 뜻이고, `slots[i] = slot`이 `Build` 반복문의
  마지막 줄이므로 **`Build`가 도중에 예외로 끊겼다**는 신호다. 다시 나오면 그 앞의 첫 예외를
  볼 것
- **첫 방에는 입장 유예가 없다.** 판을 시작할 때는 방 이동 연출을 타지 않으므로 조작이 켜진
  채로 방이 올라온다. 다른 방과 같이 맞추고 싶으면 `GameFlow.BeginRun` 쪽에 손대야 한다
- **`scripts/bake_corridor_cloud.py`** — 통로 안개의 덩이별 짙기를 굽는다. 짙기를 다시
  조정하려면 `DENSITY_MIN`만 바꿔 다시 돌린다 (`SEED`가 고정이라 배치는 그대로다).
  **원본을 제자리에 덮어쓰므로 두 번 돌리면 두 번 곱해진다** — 되돌리려면 git에서 꺼낼 것
