# Pokémon Mystery Dungeon Roguelike

포켓몬 불가사의 던전의 스프라이트 기반 탑다운 플레이와 로그라이크 진행 방식을 결합한 게임 프로젝트입니다.

플레이어는 이상해씨로 시작해 숲, 사막, 바다로 구성된 3개 층을 탐험합니다. 각 층의 전투와 이벤트를 통과하고 보스를 쓰러뜨리면 다음 진화 단계로 성장합니다.

## 핵심 정보

- 장르: 스프라이트 기반 탑다운 로그라이크
- 예상 플레이 시간: 한 판당 15~20분
- 전체 구성: 3개 층, 층마다 5개 방
- 플레이어 캐릭터: 이상해씨 진화 계열
- Unity 버전: `6000.5.3f1`
- 렌더링: Universal 2D

세부 게임 구성과 구현 우선순위는 [게임 기획 개요](docs/game-design.md)에서 확인할 수 있습니다.

## 프로젝트 열기

1. 저장소를 내려받습니다.
2. Unity Hub에서 이 저장소 폴더를 프로젝트로 추가합니다.
3. Unity `6000.5.3f1`로 프로젝트를 엽니다.
